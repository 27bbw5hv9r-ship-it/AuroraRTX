AuroraRTX v0.1 - Iris Shader Pack
==================================

INSTALLATION:
1. Ensure you have Iris 1.11.1+ and Sodium 0.9.0+ installed
2. Download this pack as ZIP
3. Place in: .minecraft/shaderpacks/
4. Launch Minecraft with Iris
5. Open Shader Options (Ctrl+Shift+S) → select "AuroraRTX"

FEATURES:
- Enhanced terrain lighting
- Beautiful water rendering
- Volumetric fog & atmospheric effects
- Bloom & glow effects
- Color grading & tone mapping
- Performance optimized for Sodium

COMPATIBILITY:
- Minecraft: 1.21+ (tested on 1.26.2)
- Iris: 1.11.1+
- Sodium: 0.9.0+

SETTINGS:
Bloom Intensity: Controls glow strength (0.0-1.5)
Fog Thickness: Controls atmospheric density (0.0-0.01)
Saturation: Color vibrancy (0.5-2.5)
Contrast: Tone contrast (0.5-2.5)
Exposure: Overall brightness (0.5-2.5)

TROUBLESHOOTING:
- If flickering: Lower BLOOM_STRENGTH
- If too dark: Increase EXPOSURE
- If lag: Disable FOG or lower FOG_DENSITY

CREDITS:
Created for Iris 1.11.1 & Sodium 0.9.0
GLSL optimized for Java Edition
